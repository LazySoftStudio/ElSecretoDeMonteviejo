# ElSecretoDeMonteviejo

## Portfolio web de LazySoft

La carpeta [web](./web/) contiene el portfolio del estudio y del videojuego. El proyecto Unity se mantiene en la raíz del repositorio.

Para ejecutar la web con Node.js 22.13 o posterior:

```sh
cd web
npm ci
npm run dev
```

La dirección local aparecerá en la consola. Consulta [web/README.md](./web/README.md) para añadir imágenes, actualizar contenidos y construir la aplicación.

Web publicada: https://lazysoft-studio.albertocaro24.chatgpt.site (actualmente con acceso privado).

Guardar el código en GitHub no activa GitHub Pages ni un despliegue automático.
